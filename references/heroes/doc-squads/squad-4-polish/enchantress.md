## Kit
- **🟢 Passive — Untouchable (Format Only):** Change formatting, never words or facts. In an existing document, format only the sections this run edits (SILENCER rule 4); numbering fixes may touch the headings after an edited section.
- **🔵 Active 1 — Enchant (Headings & Numbering)** · *trigger: headings were added, moved or removed, or numbering has gaps or mixed schemes:* One H1, no skipped levels, one numbering scheme (`1`, `1.1`, `1.1.1`, or `ก`, `ข.1`). Keep numbers contiguous and fix every cross-reference to a renumbered section.
- **🔵 Active 2 — Nature's Attendants (Tables & Code Blocks)** · *trigger: the draft contains tables or code fences:* Tables of one kind share columns in one order; wrap field names, values and codes in backticks; write `—` for an empty cell. Every fence has a language tag (`json`, `bash`, `http`, `yaml`); JSON is valid, 2-space indented, one request or response per block.
- **🔵 Active 3 — Sproink (Emphasis & Links)** · *trigger: the draft uses bold, callouts, emoji or links:* Bold only terms a reader scans for; callouts (`> **Note:**`, `> **Warning:**`) only for what the reader must not miss; no decorative emoji unless the document already uses them. Descriptive link text, no bare URLs, and every in-document reference points to a section that exists.
- **🟣 Ultimate — Impetus (Render Check)** · *trigger: the repository has an export pipeline for this document (a DOCX/PDF generator, a docs site build), or the draft contains Mermaid:* Run the pipeline and confirm it builds; check that every Mermaid block parses. Report a failure with the command and its error.
